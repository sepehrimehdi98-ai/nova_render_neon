# Class events, chat purposes and exam expiry — 13 November 2026

- The flame is confined to the next-class card inside the student homepage class schedule. It glows only when that class starts on the current Asia/Tehran calendar date. Other days have a quiet icon; exam and practice cards never receive a flame. Reduced-motion preferences disable the pulse while retaining a static glow.
- Today-class sample is persisted through the existing teacher-authorized class-events API. Exam cards are purple, practice cards green, and class cards warm orange. The original homepage composition remains restored; the small original agenda icons also distinguish event types.
- Removed the separate student chat web-topic/source field and the inactive plus button. The composer now accepts reference URLs in the message and has a native answer-purpose selector: Auto, Explanation, Example, Practice, Debug and Summary. The same selector is available in the lesson-builder conversation.
- Purpose is validated server-side, stored in queued jobs and passed into generation. Pasted links are bounded to three and resolved by the existing public-document reader. Supported hosts: docs.python.org, peps.python.org, developer.mozilla.org. HTTPS only; credentials, custom ports, other hosts and redirects are not followed. Unsupported/unreadable links produce notices, never a claim that their contents were read. Reference material remains untrusted context and does not automatically enter the shared approved RAG corpus.
- Local chat can extract linked documentation without a generative API key. Online generation still requires the existing provider key and worker; this change does not simulate generated responses. Browser testing successfully read an actual Python tutorial URL sent inside the chat, with Summary selected. Its local response is labeled as extraction/search, not a generated summary.
- Expired exams now display a persistent Persian alert stating that time is over, editing is closed and server-saved answers are finalized. Expiry comes from the teacher's duration and closing time, enforced by the server; the last-second rounding was corrected. Reopened timed-out attempts also show the notice. Failed finalization requests retain a retry/check action and do not falsely claim successful submission.

Verification: all three portal builds and the combined build passed. 33 automatic tests passed, zero failures (27 backend + 3 demo + 3 portals). New tests cover purpose validation, bounded link parsing and preventing unsupported URLs from reaching the fetcher; the existing timed-exam test now asserts the timedOut flag. Browser verified class-only glow, coloured events, inline reference reading, purpose selection and a real short teacher-scheduled exam that expired automatically and finalized its saved correct answer as 1/1.
