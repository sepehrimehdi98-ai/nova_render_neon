## Unresolved limitation
A student request for a runnable AI example was withheld by the server’s execution-verification gate. The configured production environment has no secure grader image/runner. This is distinct from document-chat and conceptual tutor responses, which passed. Server-side verified AI code examples and automatic code grading must not be represented as fully operational until a separate secure execution service is configured and tested. The execution check was not bypassed.
